## Findings considered and rejected

- **Bug: related-message coefficient signs** — The verification catch already prevents wrong answers; valid inputs that should succeed locally get routed to SageMath instead. Not a security or correctness issue — just unnecessary latency. YAGNI.
- **Bug: Batch-GCD unbounded resource consumption** — Real-world CTF inputs are small. Browser timeout catches runaway computation. YAGNI.
- **Bug: Pollard-rho testcase float precision** — Math.random bias is negligible for testcases. YAGNI.
- **Perf: Dependent-prime isqrt** — Browser limitation; can't be fixed without algorithm change. YAGNI.
- **Perf: small-fraction BigInt divisions** — 1 second worst case is acceptable. YAGNI.
- **Arch: Attack type splits** — Touches all 47 files + consumers. L effort for marginal benefit. YAGNI.
- **Dir: Attack chaining** — Product direction, not a bug fix. Would need a separate design spike.
- **Dir: Attack metadata** — Nice-to-have but no concrete user pain today. YAGNI.
